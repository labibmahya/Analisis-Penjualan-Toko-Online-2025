# Analisis-Penjualan-Toko-Online-2025
Membersihkan 512 baris data transaksi (duplikat, nilai kosong, format tidak konsisten), menganalisis omzet Rp.143 juta dengan Pivot Table, dan membuat dashboard interaktif dengan slicer. Menemukan bahwa November-Desember menyumbang 35% omzet dan 18.8% pesanan tidak menjadi pendapatan, disertai rekomendasi stok, promo, dan penaganan pembatalan.
